# Check-ins

Each check-in is **one page or less**, plus links to evidence in this repo.
Fill in the page for the week, then copy it into Canvas (or link to it).

| Week | Page | What the assignment asks for |
|------|------|------------------------------|
| 10 | [checkin-1.md](checkin-1.md) | Working prototype of the core features, Git commit history, at least one test, current blocker, next steps |
| 12 | [checkin-2.md](checkin-2.md) | Integrated features, updated tests, memory diagnostic output, approved scope changes |
| 14 | [readiness-week14.md](readiness-week14.md) | Teammate builds from the README only, demo rehearsal, list of missing evidence |

Grading: each check-in is worth 5 points for "working progress, honest
status, and next steps". Honest means: if something does not work, say so.
Only report tests you really ran.

Tip: link to a commit or a pull request, not to a branch. A branch changes;
a commit stays the same.
